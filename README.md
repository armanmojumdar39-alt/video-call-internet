# Connecto

ফোন নাম্বার ভিত্তিক ভিডিও কল অ্যাপ (Flutter + Node.js + WebRTC)। পূর্ণ পরিকল্পনা: [PLAN.md](PLAN.md)

```
connecto/
├── PLAN.md      # সম্ভাব্যতা, আর্কিটেকচার, ধাপ, খরচ
├── server/      # Node.js: OTP লগইন, কন্টাক্ট ম্যাচ, Socket.IO সিগন্যালিং, TURN ক্রেডেনশিয়াল, FCM
└── app/         # Flutter অ্যাপ (Android + iOS)
```

> **অবস্থা:** এটি MVP ভিত্তি। এই সোর্স লেখার পরিবেশে প্যাকেজ ইনস্টল করা যায়নি, তাই সার্ভারের সিনট্যাক্স চেক হয়েছে কিন্তু **সার্ভার ও অ্যাপ কোনোটাই এখনো চালিয়ে টেস্ট করা হয়নি**। প্রথম রানে ছোটখাটো কম্পাইল/ডিপেন্ডেন্সি ত্রুটি আসতে পারে।

## ১. সার্ভার চালান (পিসিতে)

```bash
cd server
cp .env.example .env      # JWT_SECRET বদলান
npm install
npm start                 # http://localhost:3000
```

ডেভ মোডে (`OTP_DEV_MODE=true`) SMS যায় না; OTP কোড সার্ভারের টার্মিনালে ছাপা হয়।
সার্ভার চেক: `http://localhost:3000/health`

## ২. অ্যাপ চালান

Flutter SDK ইনস্টল থাকতে হবে।

```bash
cd app
bash setup.sh             # android/ios ফোল্ডার তৈরি + পারমিশন যোগ (একবার)
flutter run
```

- অ্যান্ড্রয়েড এমুলেটরে ডিফল্ট সার্ভার `http://10.0.2.2:3000` কাজ করে।
- **আসল ফোনে টেস্ট:** ফোন ও পিসি একই ওয়াই-ফাইতে রাখুন, লগইন স্ক্রিনের "সার্ভার সেটিংস" এ `http://<পিসির-IP>:3000` দিন।
- টেস্টের জন্য **দুটি ফোন** লাগবে (বা একটি ফোন + একটি এমুলেটর), দুটিতেই আলাদা নাম্বারে লগইন করুন, এবং একে অপরের নাম্বার কন্টাক্টে সেভ করুন (অথবা "নাম্বারে কল" বাটন ব্যবহার করুন)।

## ৩. আসল ব্যবহারের আগে বাকি কাজ

`PLAN.md`-র ধাপ ১–৭ দেখুন। সংক্ষেপে: HTTPS + coturn, আসল SMS গেটওয়ে (`server/src/sms.js`), অ্যাপে Firebase পুশ ও নেটিভ কল UI (CallKit/ConnectionService), ডাটাবেস, নিরাপত্তা অডিট।

## ৪. GitHub দিয়ে APK বানান

`.github/workflows/build-apk.yml` পুশ করলেই GitHub নিজে APK বানায়। কম্পিউটারে Flutter ইনস্টল লাগে না।

1. GitHub-এ নতুন রিপোজিটরি খুলুন এবং এই `connecto` ফোল্ডারের সবকিছু (শুধু `server/node_modules` বাদে) `main` ব্রাঞ্চে পুশ করুন।
2. **সার্ভারের ঠিকানা সেট করুন** (না করলে অ্যাপ `10.0.2.2` ধরবে, যা আসল ফোনে কাজ করে না):
   Settings → Secrets and variables → Actions → **Variables** → New variable: `SERVER_URL` = `https://আপনার-সার্ভার` (বা `http://পিসির-IP:3000`)।
   অথবা Actions ট্যাব → Build APK → Run workflow এ ঠিকানা লিখে দিন।
3. Actions ট্যাবে বিল্ড শেষ হলে (প্রায় ১০–১৫ মিনিট) রান পেজের নিচে **Artifacts → connecto-apk** ডাউনলোড করুন, ভেতরে `connecto.apk`।
4. ফোনে APK ইনস্টল করতে "Unknown sources" অনুমতি দিতে হবে।
5. স্থায়ী ডাউনলোড লিংক চাইলে ট্যাগ দিন: `git tag v1.0.0 && git push --tags`। তখন APK **Releases** পেজেও যুক্ত হবে।

নোট: APK ডিবাগ কী দিয়ে সাইন হয়, যা নিজে ইনস্টলের জন্য ঠিক আছে। Play Store-এ দিতে নিজের keystore লাগবে। অ্যাপে HTTP (cleartext) চালু আছে যাতে `http://IP:3000` দিয়ে টেস্ট করা যায়; HTTPS সার্ভার নিলে এটি বন্ধ করুন।

## ৫. ইন্টারনেটে চালু করা (ফোন থেকে ফোনে, যেকোনো নেটওয়ার্কে)

**ধাপ ১ — সার্ভার অনলাইনে দিন (ফ্রি):** কোড GitHub-এ পুশ করার পর [render.com](https://render.com) → New → **Blueprint** → আপনার রিপোজিটরি বাছুন। `render.yaml` দেখে নিজেই সার্ভার তৈরি করবে এবং `https://connecto-server-xxxx.onrender.com` ঠিকানা দেবে।

**ধাপ ২ — TURN (মোবাইল ডেটায় কল লাগার জন্য জরুরি):** [metered.ca](https://www.metered.ca) এ ফ্রি অ্যাকাউন্ট খুলে একটি অ্যাপ বানান। Render-এ সার্ভিসের Environment-এ `METERED_APP` (অ্যাপের নাম) ও `METERED_API_KEY` বসান। এটা ছাড়া অনেক মোবাইল নেটওয়ার্কে (CGNAT) কল সংযুক্ত হবে না।

**ধাপ ৩ — APK:** GitHub Variables-এ `SERVER_URL` = ধাপ ১-এর ঠিকানা দিয়ে Actions থেকে APK বানান (সেকশন ৪)।

**লগইন:** ডিফল্ট `OTP_MODE=off`। শুধু নিজের নাম্বার দিলেই ঢোকা যায়, SMS কোড লাগে না। **ঝুঁকি:** নাম্বার যাচাই হয় না, তাই অন্য কেউ আপনার নাম্বার দাবি করতে পারে। শুধু পরিবার/বন্ধুদের ব্যক্তিগত ব্যবহারে রাখুন। সবার জন্য খুললে `OTP_MODE=sms` করে `server/src/sms.js`-এ SMS গেটওয়ে যুক্ত করুন।

**মনে রাখুন:**
- রিসিভারের অ্যাপ **খোলা থাকতে হবে** (ব্যাকগ্রাউন্ডে থাকলেও চলে, কিন্তু সিস্টেম মেরে দিলে নয়)। অ্যাপ বন্ধ থাকলে রিং আসার জন্য Firebase পুশ লাগবে, যা এখনো অ্যাপে যুক্ত নেই।
- Render ফ্রি সার্ভার ১৫ মিনিট নিষ্ক্রিয় থাকলে ঘুমিয়ে যায়; জাগতে ~১ মিনিট লাগে। নিয়মিত ব্যবহারে প্রায় $7/মাসের পেইড প্ল্যান বা VPS ভালো।
- সার্ভার রিস্টার্ট হলে ইউজার তালিকা মেমরি থেকে মুছে যায়, তবে অ্যাপ আবার সংযুক্ত হলেই নিজে থেকে ফিরে আসে (লগইন লাগে না)।
- কল করতে দুজনেরই অ্যাপ ও একই সার্ভার লাগবে; কন্টাক্টে যাদের Connecto আছে শুধু তাদেরই কল বাটন দেখাবে।
